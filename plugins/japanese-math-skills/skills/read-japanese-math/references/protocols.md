# 方式別レビュー

## continuous — 逐次初見読解

最初のメッセージではガイド、読者条件、方式だけを受け取り、準備完了を返す。
原稿パス・本文は次のメッセージから受け取る。
同じ読者が文書順に渡される累積部分だけを読み、後の内容を使って最初の理解を修正しない。
後続部分、PDF、監督側の区切り地図へアクセスしない。

各回、受領範囲、初出の用語、現時点の理解、立ち止まった箇所、読者が補った推論を記録する。
後から説明された場合は最初の観察を消さず、解決した時点を別記する。
文の量化、参照先、定理の役割、節の接続を確認する。
中立的な詳しさの契約は開示済み箇所の分だけ受け取る。
全原稿が届く前に全体の合格判定を出さない。
最終報告では実読範囲と指摘をまとめ、`Continuous verdict: PASS`、`Continuous verdict: FAIL`、`Continuous verdict: UNTESTABLE` の一行で終える。
PASS は与えられた読者条件での説明上の合格を意味し、数学の認定ではない。

## editorial — 全体編集読解

ガイドと方向だけで準備し、その返答後に凍結原稿とSHA-256、読者条件を受け取る。
実際の入力バイト列のハッシュを検証してから全文を読む。
以前のレビュー、修正案、予想診断は受け取らない。

必要性と正確さを別々に点検する。
注意、限定、接続文、反復、非公式な別名を削ると読者が何を失うかを具体化する。
残す主張や結果への言及について、対象、述語、出典、指示対象が明確か確認する。
「理解できる」「数学的に正しい」だけではその段落の必要性を認定しない。
削除・短縮・置換の方向を示す場合も原稿を直接編集しない。

全体を読めていなければ UNTESTABLE とし、実読範囲を記す。
最後に `Editorial verdict: PASS`、`Editorial verdict: FAIL`、`Editorial verdict: UNTESTABLE` の一行を記す。
初見の逐次読みや証明の正しさはこの判定の対象外。

## delta — 限定差分読解

基準版と変更版、対象修正単位の完全なID一覧、変更箇所、十分な前後文、読者に見える成功基準、範囲外事項を受け取る。
診断、望ましい答え、指定の修正文は受け取らない。
各IDについて、現在何を伝える文か、基準を満たすか、残る補完推論、副作用を報告する。
未読の依存や不足資料があれば UNTESTABLE とする。

最後に実際に点検したID集合と `Delta verdict: PASS`、`Delta verdict: FAIL`、`Delta verdict: UNTESTABLE` を記す。
PASS は全指定IDが与えられた資料の範囲で基準を満たした場合だけ。
前の全体 FAIL、未提示の箇所、未実装の修正は閉じない。
構成や読書順路の変化は差分レビューの限界として報告し、追加レビューを勝手に起動しない。
