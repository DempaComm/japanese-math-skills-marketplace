<a id="reduction"></a>
## 目標を扱いやすい形へ帰着する

元の結論を、証明しやすい条件に置き換えたい。

- 前提：帰着先から元の結論が従う関係。
- 補う説明：同値なのか、十分条件だけなのか。
- 選び分け：無限性を任意の上限越えへ移す例と、開性を各点の内点性へ移す例を比べる。

- [JP-P02](proof-passages.md#jp-p02) 無限性を「任意の上限を越える構成」へ帰着する — 無限性を構成で示すとき
- [JP-P08](proof-passages.md#jp-p08) 全体の開性を点ごとの内点性へ帰着する — 全体の開性を各点で示すとき

<a id="contradiction"></a>
## 背理法・最小反例で矛盾を導く

直接構成するより、反例の存在から矛盾を出しやすい。

- 前提：否定した命題の正しい量化と、最小元を選べる順序。
- 補う説明：最後にどの仮定へ反したか。
- 選び分け：存在を否定して不等式で矛盾させる一意性の議論は別の目的として案内する。

- [JP-P01](proof-passages.md#jp-p01) 反例集合を定義し、最小元から矛盾を導く — 最小反例を使うとき

<a id="construction"></a>
## 条件を保ちながら対象を構成する

写像や空間を、要求する性質に合わせて作りたい。

- 前提：構成の各段階で維持する条件。
- 補う説明：構成できることと完成後の性質の確認。
- 選び分け：交互に拡張する写像と、反例の性質を先に決める空間構成を使い分ける。

- [JP-P06](proof-passages.md#jp-p06) 交互に定義域と値域を広げて写像を組み立てる — 写像を交互に拡張するとき
- [JP-P12](proof-passages.md#jp-p12) 失敗させたい性質を先に掲げ、空間を構成する — 要求する性質から反例空間を設計するとき

<a id="induction"></a>
## 帰納法で次の段階へ進む

添字nでの性質をn+1へ渡したい。

- 前提：初期値、帰納法の仮定、漸化式が使える範囲。
- 補う説明：初期段階と帰納段階を別に確認する。
- 選び分け：等式の帰納的証明と、対象そのものの帰納的構成を区別する。

- [JP-P14](proof-passages.md#jp-p14) 帰納法の仮定を漸化式へ代入し、次の添字の形へ戻す — 漸化式の等式を帰納的に示すとき
- [JP-P06](proof-passages.md#jp-p06) 交互に定義域と値域を広げて写像を組み立てる — 写像を交互に拡張するとき

<a id="well-defined"></a>
## 定義が意味を持つことを確認する

和・選択・商などで定めた対象を使いたい。

- 前提：和が扱える条件、または変えてよい選択の一覧。
- 補う説明：値の存在、選択への独立性、連続性は別の確認である。
- 選び分け：局所有限な和の例を入口にする。商の例は独立性の確認が一部に限られることを読む比較例。

- [JP-P19](proof-passages.md#jp-p19) 局所有限性によって和を定義し、連続性へつなげる — 関数族の和で写像を作るとき
- [JP-P21](proof-passages.md#jp-p21) 選択への独立性のうち、何を固定したかを区別する — 選択への独立性の確認範囲を点検するとき

<a id="uniqueness"></a>
## 存在から一意性へ目標を切り替える

対象を得た後、二つあれば一致することを示したい。

- 前提：比較する二対象が同じ仮定を満たすこと。
- 補う説明：存在の証明を終えた地点と、距離が零になる理由。
- 選び分け：構成や存在の証明を含まない一意性部分として読む。

- [JP-P09](proof-passages.md#jp-p09) 存在を示した後、一意性の目標へ切り替える — 二つの解の一致だけを示すとき

<a id="cases"></a>
## 場合分けで可能性を尽くす

一つの議論では扱いにくい対象を条件で分けたい。

- 前提：場合の網羅性と、各場合で共通する目標。
- 補う説明：どの条件で分け、各場合が何を与えたか。
- 選び分け：点の所属で近傍を作る例と、既存の分類結果を適用する例を比べる。

- [JP-P15](proof-passages.md#jp-p15) 点が開集合族に入るかどうかで場合を分ける — 任意の点で二通りの近傍を選ぶとき
- [JP-P05](proof-passages.md#jp-p05) 場合分けごとに既存の結果を適用して分類を閉じる — 既知の結果を場合ごとに適用するとき

<a id="estimates"></a>
## 評価を組み合わせて結論へ進む

量の上界・下界から性質を導きたい。

- 前提：定数の依存先、分母の非零性、評価が有効な範囲。
- 補う説明：一つの評価が次の連続性や存在にどう使われるか。
- 選び分け：ノルムの両側評価、近似から所属を得る評価、濃度評価は目的が異なる。

- [JP-P17](proof-passages.md#jp-p17) 上からの評価で連続性を得て、コンパクト性で下からも抑える — 連続性とコンパクト性で両側の定数を得るとき
- [JP-P03](proof-passages.md#jp-p03) 近似点を選び、評価から所属を結論する — 近似点が所望の近傍に入ると示すとき
- [JP-P13](proof-passages.md#jp-p13) 埋め込みから濃度評価へ移り、最小の開基を選ぶ — 埋め込みを濃度評価へ使うとき

<a id="limits"></a>
## 近似や部分列から極限へ渡す

各段階の解から目的の解を得たい。

- 前提：収束の種類、極限点の存在、必要な連続性。
- 補う説明：点と関数が同時に動くときの二種類の誤差。
- 選び分け：一様収束を使うこの例を、各点収束だけの場合にそのまま移さない。

- [JP-P16](proof-passages.md#jp-p16) 補助関数の零点を選び、一様収束と部分列で極限へ渡す — 近似解の収束部分列から共通零点を得るとき

<a id="compactness"></a>
## コンパクト性で有限化・共通点を得る

点ごとの情報を有限個に絞るか、集合族の共通点を得たい。

- 前提：開被覆または閉集合族が満たすコンパクト性の適用条件。
- 補う説明：有限部分被覆と有限交叉性のどちらを使ったか。
- 選び分け：管状近傍の有限化を入口にし、閉集合の共通点から密度へ戻る例と比較する。

- [JP-P20](proof-passages.md#jp-p20) 有限部分被覆を取り、近傍の有限交叉で一様化する — 点ごとの積近傍を一つの近傍へまとめるとき
- [JP-P10](proof-passages.md#jp-p10) コンパクト性の出力を包含式で元の目標へ戻す — 共通点の存在を密度へ戻すとき

<a id="equivalence"></a>
## 同値性の各方向を整理する

複数の条件が同じ内容を表すことを示したい。

- 前提：各条件の正確な範囲と、示すべき矢印。
- 補う説明：一方向、逆方向、対偶のどれを示しているか。
- 選び分け：二つの対偶を示す例と、多条件の同値性の一方向だけを扱う例を区別する。

- [JP-P18](proof-passages.md#jp-p18) 二つの対偶を方向別に示して同値性を閉じる — 二つの対偶で同値性を示すとき
- [JP-P16](proof-passages.md#jp-p16) 補助関数の零点を選び、一様収束と部分列で極限へ渡す — 近似解の収束部分列から共通零点を得るとき

<a id="existence"></a>
## 個数の比較から存在を導く

具体的な対象を選ばず、足りなさから存在を示したい。

- 前提：比較する二つの集合族と、その濃度の厳密な大小。
- 補う説明：どちらの集合族に含まれない元が得られたか。
- 選び分け：非構成的な個数比較と、上限を越える数の構成を区別する。

- [JP-P11](proof-passages.md#jp-p11) 二種類の集合族の個数を比べ、存在を導く — 具体的な反例を選ばず存在を得るとき
- [JP-P02](proof-passages.md#jp-p02) 無限性を「任意の上限を越える構成」へ帰着する — 無限性を構成で示すとき

<a id="local-global"></a>
## 局所の情報を全体の性質へ戻す

点ごとの結論から開性や稠密性を結びたい。

- 前提：任意に選んだ点・近傍と、局所結果の適用条件。
- 補う説明：点の任意性を回収して全体の結論へ戻る一文。
- 選び分け：各点の内点性から開性へ進む例と、近似点から任意の近傍との交わりを得る例を比べる。

- [JP-P08](proof-passages.md#jp-p08) 全体の開性を点ごとの内点性へ帰着する — 全体の開性を各点で示すとき
- [JP-P04](proof-passages.md#jp-p04) 補題の近似を包含関係で移し、任意性を回収する — 補題の近似を稠密性へ使うとき

<a id="application"></a>
## 既知の定理を使える形に整える

定理の仮定に合う対象を作って、その結論を使いたい。

- 前提：引用する定理の仮定と、今回の対象との対応。
- 補う説明：引用名だけで済ませず、何を入力し何を得たか。
- 選び分け：縮小する被覆を整える例と、埋め込みの結果を数え上げへ使う例を比べる。

- [JP-P07](proof-passages.md#jp-p07) 縮小する開被覆を構成し、既知の原理で閉じる — 被覆を整えて既知の完全性原理を使うとき
- [JP-P13](proof-passages.md#jp-p13) 埋め込みから濃度評価へ移り、最小の開基を選ぶ — 埋め込みを濃度評価へ使うとき

## 整理した範囲

179ファイルの検索候補と既存用例を照合し、14の目的に21例を割り当てた。既存18例に、局所有限な和、コンパクト性による有限化、選択への独立性の一部確認を補った。
同じ用例を複数の目的へ案内しても、独立した別用例として数えない。写像の帰納的構成と定義の正当性、ノルムの同値と命題の同値、一様収束と単なる各点収束を区別した。
超限帰納法・測度論固有の極限定理・図式追跡などの専門的な運びを網羅した案内ではない。原文の証明の正しさや、今回読んでいない依存定理の証明を認証しない。
