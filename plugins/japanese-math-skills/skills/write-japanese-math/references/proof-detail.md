# 著者が承認した証明の省略

意図的な証明省略や短い議論は、対象文書の私的な判断記録を参照して尊重する。
記録がなければ承認を推測しない。新しい著者判断は許可された作業記録に保存し、保存できなければその事実を報告する。

記録には ID、対象文書・版、ラベルか厳密なアンカー、対象の推論、仮定、承認された省略範囲、想定読者、残すべき内容、著者発言の根拠、適用確認を残す。
日付や発言を推測しない。私的記録を本文や投稿物へ入れない。
承認は記述の詳しさに関するものであり、数学的正しさの認定ではない。

有効な判断と同じ範囲の省略を再び欠陥としない。必要なら報告で `accepted brevity` と ID を使う。
読者が立ち止まった事実は保持するが、それだけで承認済み省略の撤回を要求しない。
新しい仮定の欠落、依存関係の変更、省略範囲外での使用など、具体的な新問題は別に報告する。
行番号やハッシュの変化だけでは再承認を要求しない。
判断の意味が変わるときにだけ適用範囲を再確認し、必要な著者判断を特定する。

独立レビュアーには私的台帳を渡さない。監督側は凍結版と照合した中立的な契約を作り、ID、許可された原稿内の箇所、省略範囲、前提知識、明示すべき数学的接続だけを伝える。
予想される指摘や証明のヒントを加えない。逐次レビューでは、すでに開示した原稿に対応する項目だけを渡す。
契約は指摘を見てから追加せず、レビュー開始前に凍結する。
