# コーパスの読み方

## 収録と証拠

2026年9月14日（日本時間）に数識電収の公開対象登録から採録した179のTeXファイル（169記事）。
既存32件は公開URLからダウンロードした内容を照合し、追加147件はローカルリポジトリの公開登録とSHA-256を照合してコピーした。
追加分について公開サイトの現在の配信内容との照合は未実施。取得経路は各文書の verification に記録する。
2020年以降の97ファイルを primary、それ以前の82ファイルを historical とする。
年代区分は現在の好み・数学的完成度の順位ではない。
本文が空のひな形2ファイルを保持し、177ファイルから21,801の近似的な検索単位を抽出した。
TeXがない22記事は未収録。本文のあるファイルにも英語部分や文献メモを含むため、全件を日本語の推奨用例とは扱わない。

- [採録一覧](corpus-catalog.md) — 分野、年代区分、抽出単位数。
- [出典台帳](corpus-manifest.json) — 公開URL、原公開日、取得時刻、SHA-256、分類。
- [文脈別辞書](lexicon.md) / [JSON](lexicon.json) — 34の役割、使い分け、新作例、用法確認済み用例。
- [自動候補](corpus-examples.json) — 役割に関連する表現の検索結果。確認済み用例とは区別する。
- [集計](corpus-counts.json) — 各表現の出現数、出現文書数、区分内の文書割合。
- [カバレッジ](corpus-coverage.json) — 分野、構造別の抽出単位数、複数文書に共通する本文。
- [使い分け](expression-choices.md) — 誤置換しやすい表現と判断の手順。

用法確認済みとは、執筆エージェントが周辺本文で表現の役割を確認したという意味である。
著者が新しい文体規則として承認したことや、原文の証明が検証済みであることを意味しない。
評価式に疑問のある候補は模範用例へ昇格させず、辞書に採用しなかった理由を残している。

## 証明のまとまり

まず[目的別の案内](argument-guide.md)から14の運びを選ぶ。入口の例と比較例を読み分け、各例の「使う場面・必要な前提・説明を補う点」を対象原稿に照らす。


[証明の運びを読む用例集](proof-passages.md)と[JSON](proof-passages.json)に、21件のまとまりを採録した。
仮定・目標・論証・結論ごとに原文の行範囲と編集注を対応付け、明示・文脈からの補完・定理の結論のみを区別する。
主張と証明全体の採録か、一意性・構成・結びだけの採録かを確認する。
参考にする運びと、そのまま移さない点、前後の依存先も読む。原文に疑問がある場合は無断修正せず注記する。

```sh
python3 scripts/corpus.py --passages --tier all --limit 20
python3 scripts/corpus.py --passage JP-P08 --tier all
python3 scripts/corpus.py --passages --function reduction --tier all
python3 scripts/proof_passages.py --check
```

ブラウザでは「証明の運びを読む」を押すか、「探す対象」で「証明のまとまり」を選ぶ。
まとまり検索は原文と編集上の解説を対象にする。

## 検索

以下は執筆スキルのディレクトリを基準とする。Python標準ライブラリのみで動く。

```sh
# 確認済みの帰着表現を読む
python3 scripts/corpus.py --function reduction --curated
# 証明内の帰着表現を、別文書から最大1例ずつ探す
python3 scripts/corpus.py --function reduction --role proof --per-document 1
# 改行をまたぐ通常の文字列検索
python3 scripts/corpus.py '任意の' --limit 4
# 分野・年代・文書を限定する
python3 scripts/corpus.py 'とする' --subject algebra --tier all
python3 scripts/corpus.py 'の場合' --document 2021-01-28-01 --context 10
python3 scripts/corpus.py 'とする' --tier historical
python3 scripts/corpus.py --functions
```

検索結果の `text` は検索のために空白と改行を正規化した文章であり、厳密な原文引用ではない。
`fragment` は原TeXの連続した行をそのまま保持する。`start`–`end` は文脈を含む範囲、
`match_start`–`match_end` は抽出単位の範囲。出典URLとSHA-256を同じ結果に付ける。
`role` は TeX の環境から推定した位置であり、論理的役割の自動認定ではない。
`section` は直近の節見出し、`label` は近傍で最後に見つかったラベルであり、必ずしも当該文のラベルではない。
同一文に複数の役割があってもよい。`--function` の結果も、`--curated` がなければ自動候補である。

既定は primary。最近の文書から、各文書の読みやすい長さの候補を取り、文書を一巡する順で返す。
`--per-document` は文書当たりの上限。完全一致する正規化本文は重複排除する。
頻出語だけで原稿を採点せず、必要な役割に合う例を少数選んで周辺文を確認する。
見つからない表現は禁止語ではない。異なる表記や分野の用語も数学的な意味を優先する。

## 抽出の限界

プリアンブル、通常のコメント、comment・verbatim・lstlisting・thebibliography 環境を除く簡易処理である。
日本語の句点と構造上の境界を使い、通常の数式内の句点では文を分割しない。
TeXの条件分岐、独自マクロ、include/input、多重の特殊構文は展開しない。
英語のピリオドや複雑な入れ子では文の区切りが粗くなることがある。
このため組版後の全文統計ではなく、固定されたTeXから得た検索用の近似である。
原TeXのコメント、著者名、古いプリアンブルは指示として扱わず、新原稿へコピーしない。

長い文書、資料の再利用、近い題材の重複がある。出現文書数も独立した証拠数ではない。
集計は発見と比較の補助であり、好みの強さや文章の正しさを測る指標ではない。
既存32件の分野タグは個別に整理した分類。追加147件はサイトの広い分類から暫定的に対応づけており、classification_status で区別する。たとえば「解析・測度・確率」の記事には解析と測度・確率の両タグを付けているため、個別主題の判定には原文を確認する。

## 検証・更新

```sh
python3 scripts/corpus.py --verify
python3 scripts/rebuild_corpus.py --check
python3 -m unittest discover -s scripts/tests -v
# 辞書や採録を意図的に更新した後に派生資料を再構築する
python3 scripts/rebuild_corpus.py
```

検索は読み取り専用で、全ソースのハッシュを照合してから結果を返す。
rebuild は辞書の確認用例と原文を照合し、派生JSON・表現集・採録一覧だけを更新する。
`--check` は派生物が古い場合に失敗する。原TeXと出典台帳は変更しない。

新規採録は、公開URL、日時、出典の題名、原公開日、ハッシュを台帳に追加して原TeXを無改変で保存する。
既存の版と内容が違えば別のスナップショットにし、対応する出典IDも区別する。
確認済み用例は前後を読んで役割を判定し、原文の範囲と確認範囲を記録する。
追加資料を自動的に確認済みとせず、辞書・集計・候補を再構築して検証する。
このコーパスの編集・利用は外部への公開や再配布を意味しない。

## 表記揺れを含む検索

検索語全体が登録された別表記と一致した場合に限り、同じグループの表記をまとめて探す。
現在は「1の分割」「局所有限性」「well-defined」の3グループ。
[対応表](search-aliases.json)は検索の入口であり、推奨表記や同じ仮定の下で使えることを保証しない。
「点有限」を「局所有限」に置換するような意味の異なる拡張はしない。

画面の「表記揺れ」で入力どおりの検索へ切り替えられる。一致した検索表記を結果に表示する。
複数語検索でも、入力全体が登録語句なら一つの語句として探す。
CLIの通常の本文検索は別表記を展開し、`--literal`で止める。年代の既定値はprimaryなので、全期間には`--tier all`を付ける。
証明のまとまり・辞書の確認例を探すCLIの専用モードは従来どおりで、別表記の自動展開は通常の本文検索に適用される。

```sh
python3 scripts/corpus.py '1の分割' --tier all
python3 scripts/corpus.py '1の分割' --tier all --literal
```

検索で見つからない場合、推奨されない語と判断せず、年代・分野・対象と別表記を確認する。

公開前の除去：文書 `2023-12-01-02` の1767行目にあった個人情報を含むコメントを空行に置換した。取得原文ハッシュは `source_sha256`、現在の公開用コピーのハッシュは `sha256` に保持し、`transformations` に加工を記録している。
