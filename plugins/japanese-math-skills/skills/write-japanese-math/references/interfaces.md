# 数学的な接続の点検

語句の機械的な置換より、文と数式の間で何が定義・固定・主張されたかを確認する。

- 量化は式の前に置く。各式について本当に動く変数だけを束縛し、固定済みの変数を再び任意化しない。
- 「各 $x$ に対してある $\delta$」と「ある $\delta$ がすべての $x$ に対して」を交換しない。
- 文を分割しても、一文目の量化を二文目に無条件で持ち越さない。必要なら依存を再明示する。
- $\mu_X:\mathcal D(X)\to\mathcal P(X)$ では $X$ の範囲と各写像の定義域・値域を示す。
- 同時に条件を満たす空間、写像、誤差関数などは一組の存在として述べ、個別の存在と混同しない。
- 同値類とその代表元を区別する。点ごとの式を書く前に代表を選び、族の添字と所属先を定義する。
- 係数ベクトルとそれから構成する関数、元の測度と押し出し測度をそれぞれ定義し関係を示す。
- 積分は変数、領域、測度を合わせて点検する。上限・下限では対象集合と許容条件を示す。
- 収束はノルム・位相・一様性の範囲を特定する。極限や積分の交換には適用する仮定を示す。
- 下限を最小値と呼ぶには達成が必要。証明の途中で強めた仮定を以前の結論へ遡及させない。

例えば連続性の説明用に作った次の文では依存先が見える。

> $x\in X$ と $\varepsilon>0$ を固定する．$f$ は $x$ で連続なので，ある $\delta>0$ が存在して，$d_X(x,y)<\delta$ を満たすすべての $y\in X$ に対して $d_Y(f(x),f(y))<\varepsilon$ が成り立つ．

これは新作例であり、コーパスからの引用ではない。一様連続性を主張する文へ流用する際は量化順序を確認する。
