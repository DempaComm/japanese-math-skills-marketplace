# 日本語数学文書用スキル

既存の論文用スキルを基礎に、日本語の論文・解説・講義ノート向けに適応した2本。

- `write-japanese-math` — 執筆、和訳を伴う改稿、推敲。
- `read-japanese-math` — 明示的に委任された独立レビュー。

使い方の例

> $write-japanese-math を使って、この定理と証明を日本語の解説にしてください。読者は学部3年程度です。

> $write-japanese-math を使って第2節を推敲してください。定理の主張とラベルは変更しないでください。

> 別エージェントに $read-japanese-math を使わせ、凍結したこの原稿を editorial 方式でレビューしてください。

169記事に属する179の公開TeXファイルの出典・用例・ハッシュを執筆スキルに同梱する。
全文を毎回読み込まず、文脈別表現と検索スクリプトを使う。
独立レビューは執筆者の作業履歴を渡さずに開始する必要がある。

`skills/` の2フォルダを同じスキル探索ディレクトリに配置して使う。
初版 **v0.1.0**。ライセンスと適用範囲は [LICENSE.md](LICENSE.md)、著作者・出典・加工内容は [ATTRIBUTION.md](ATTRIBUTION.md) を参照。

コーパスは34の文章上の役割を整理し、34件の用法確認済み例と408件の自動候補を分けている。改行をまたぐ検索、分野・定理環境による絞り込み、重複除外に対応する。詳しくは [コーパスの読み方](skills/write-japanese-math/references/corpus-method.md) と [文脈別辞書](skills/write-japanese-math/references/lexicon.md) を参照。

## ブラウザで検索する

[日本語コーパス検索](http://127.0.0.1:8769/) を開く。
サーバー停止中は `検索.command` をダブルクリックするか、次を実行する。

```sh
python3 viewer/serve.py
```

起動時に原TeXのハッシュを照合し、最新のコーパスと辞書から閲覧データを生成する。
ターミナルを閉じるか Ctrl-C で停止する。ポートが使用中なら `python3 viewer/serve.py --port 8770` のように変更できる。

語句の連続一致／同じ文にすべての語、用法確認済み例、文章の役割、年代、分野、文書、定理環境で絞り込める。
「本文と出典を見る」から前後の原TeX、追加の文脈、同じ文章の掲載箇所を読める。
原文と出典のコピー、公開ページへのリンク、結果のページ送りがある。
検索条件はURLに残る。初期画面は用法確認済み例を表示する。

## 導入

ZIPを展開し、`skills/write-japanese-math` と `skills/read-japanese-math` の2フォルダを、利用環境のスキル探索ディレクトリに一緒にコピーします。レビュー用スキルが執筆基準を参照するため、2フォルダを隣接させてください。既存の同名スキルがある場合は、先に退避してから更新してください。ライセンスと出典の表示は各フォルダ内にも同梱しています。

検索ツールには **Python 3.10以上**が必要です。追加PythonパッケージやTeXのインストールは不要です。閲覧にはJavaScriptが有効なブラウザを使います。展開したパッケージのルートで起動してください。

```sh
python3 viewer/serve.py
python3 skills/write-japanese-math/scripts/corpus.py '1の分割' --limit 3
python3 skills/write-japanese-math/scripts/corpus.py '1の分割' --literal --tier all --limit 3
```

「1の分割」「局所有限性」「well-defined」は登録された別表記も検索します。本文CLIでは `--literal`、画面では「入力どおりに探す」で展開を無効にできます。CLIの既定は2020年以降で、`--tier all` は全年代です。

## 初版の検証と限界

原文ハッシュ・出典・用例の範囲を検査し、検索と分類の自動テストを実施しています。全原稿の数学的検証、独立した利用評価、ブラウザの実操作・見た目の検査は完了していません。TeXのない22記事は未収録です。詳しくは [検査記録](publication/validation.md) を参照してください。

公開用ZIPは収録対象を限定して作成します。ローカルの改稿事例、会話履歴、作業環境の設定は配布対象外です。

公開用コピーの例外：`2023-12-01-02` のTeXコメント1行から個人情報を除去し、空行として行番号を保っています。残る178ファイルは無改変です。収録マニフェストには公開用コピーのハッシュ、取得原文のハッシュ、加工箇所を区別して記録しています。元サイトの原稿は変更していません。
